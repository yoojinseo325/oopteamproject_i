## 1.1.0 · 2026-11-02

- 6단계 순차 학습 경로, 완료/현재/잠김 상태, 앞으로 나올 문제와 규칙 숨김.
- 홈에서 현재 단계 시작, 결과에서 다음 단계 바로 시작, 완주 후 계속 도전.
- 별도 복습 목록 메뉴 제거. 새 상황 중간에 이전 판단을 연습하는 다른 문항을 자동 삽입.
- 반복해서 막히면 기본 상황 우선, 연속 독립 해결에 따라 1·3·7일 간격 적용.
- 발견한 규칙만 사전에 공개, 개인 메모는 선택 기능으로 유지.
- 사용자별 steps.tsv 추가. 기존 풀이·북마크·메모를 보존하며 새 단계 경로는 STEP 1부터 시작.
- 완료 저장 실패 시 진도 유지 및 재시도, 중간 종료·재실행·사용자 분리 검사.
- 검증: 기존 서비스 161개, 단계/자동 재출제 35개, Swing 63개 통과.
