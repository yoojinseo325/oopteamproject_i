# KBO 선수·구단 구성 · V1.2

확인일: **2026-11-02**. 선수 소속은 아래 KBO 공식 등록/기록 자료와 구단 선수단 페이지에서 확인한 2026시즌 구성을 사용합니다. 실시간 이적·엔트리 동기화 기능은 없습니다.

모든 문항은 학습을 위해 만든 가상 상황입니다. 실제 경기에서 해당 선수가 실수하거나 그 판정을 받았다는 뜻이 아닙니다. 문제의 규칙 조건·정답·단서 ID는 유지하고 선수 이름과 구단 정보를 연결했습니다.

## 갱신 방법

1. 선수 소속을 변경할 때 공식 자료를 다시 확인하고 players.tsv의 teamId를 수정합니다.
2. matchups.tsv와 scenes.tsv의 공격/수비 배정도 함께 변경합니다. Catalog가 소속 불일치를 거부합니다.
3. 질문 본문의 이름과 팀도 수정하고, 정답 조건을 바꾸지 않았는지 확인합니다.
4. 색상은 teams.tsv 한 곳에서 변경합니다. test.cmd로 연결·색상·클릭·전체 학습 흐름을 검사합니다.

기존 사용자 파일 형식은 변경하지 않으며 단계 진도, 제출 기록, 북마크, 메모는 그대로 이어집니다.
